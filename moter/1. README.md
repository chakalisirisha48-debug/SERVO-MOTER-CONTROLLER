# Servo Motor Controller using Verilog

## Overview

This project implements a **Servo Motor Controller** using Verilog HDL.

A hobby servo motor can be controlled by a PWM signal. The position of the servo is determined by the width of the PWM pulse.

This project generates a PWM control signal with a period of approximately **20 ms (50 Hz)**.

Three servo positions are supported:

* 0°
* 90°
* 180°

## Features

* Verilog HDL implementation
* PWM-based servo control
* 50 Hz PWM frequency
* 0° position control
* 90° position control
* 180° position control
* Synchronous digital design

## Servo PWM Principle

A typical servo expects a PWM signal with a period of approximately 20 ms.

The pulse width determines the servo position.

| Position | Approximate Pulse Width |
| -------- | ----------------------: |
| 0°       |                    1 ms |
| 90°      |                  1.5 ms |
| 180°     |                    2 ms |

The remaining time in the 20 ms period is LOW.

Example:

```text
0°:

PWM  ┌───┐
     │   │
─────┘   └────────────────
     1 ms       19 ms


90°:

PWM  ┌──────┐
     │      │
─────┘      └─────────────
     1.5 ms     18.5 ms


180°:

PWM  ┌────────┐
     │        │
─────┘        └───────────
      2 ms       18 ms
```

## Interface

| Signal      | Direction | Description              |
| ----------- | --------- | ------------------------ |
| `clk`       | Input     | System clock             |
| `reset`     | Input     | Active-high reset        |
| `angle`     | Input     | Servo position selection |
| `servo_pwm` | Output    | PWM control signal       |

## Angle Selection

The `angle` input is 2 bits:

| `angle` | Position |
| ------- | -------- |
| `00`    | 0°       |
| `01`    | 90°      |
| `10`    | 180°     |

## Working

1. The controller receives the system clock.
2. A counter generates a 20 ms PWM period.
3. The selected angle determines the pulse width.
4. The PWM output remains HIGH for the required pulse width.
5. The output becomes LOW for the rest of the 20 ms period.
6. The process repeats continuously.

## PWM Timing

For a 1 MHz clock:

```text
Clock period = 1 us

20 ms period = 20,000 clock cycles

1 ms pulse  = 1,000 clock cycles
1.5 ms pulse = 1,500 clock cycles
2 ms pulse  = 2,000 clock cycles
```
